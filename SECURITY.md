# Security Policy

## Reporting a vulnerability

Please **do not** open a public GitHub issue for a suspected security
vulnerability. Instead, email **stack@xten.au** with:

- A description of the issue and its potential impact.
- Steps to reproduce, or a proof of concept if you have one.
- Any affected version/commit information.

You should receive an acknowledgement within a few business days. Once
a fix is available, we'll coordinate on disclosure timing with you
before any public writeup.

## Supported versions

This project does not yet have tagged releases — until it does, only
the current `main` branch is supported. Once versioned releases begin,
this section will list which lines receive security fixes.

## Scope

This policy covers the application code in this repository. It does
not cover:

- Vulnerabilities in third-party dependencies (report those upstream —
  though we'd still appreciate a heads-up so we can update).
- Issues that require physical or already-compromised-host access to
  exploit.
- Social engineering.
